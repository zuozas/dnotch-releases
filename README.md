# dNotch releases

Downloads and release notes for [dNotch](https://dnotch.app), the Mac app that hides the notch behind a black menu bar, tidies menu bar icons and puts live widgets beside the notch.

**[Download the latest version](https://github.com/zuozas/dnotch-releases/releases/latest/download/dNotch.dmg)** · [All releases](https://github.com/zuozas/dnotch-releases/releases) · [dnotch.app](https://dnotch.app)

Every download is signed with Developer ID and notarized by Apple. dNotch needs macOS Golden Gate 27 or later, and checks this page for updates by itself.

Questions or problems: [support@dnotch.app](mailto:support@dnotch.app). This repository holds releases only; dNotch's source isn't public.
